# Final Comprehensive Technical Examination

This examination assesses 24 weeks of cumulative DevOps engineering knowledge across Systems, Networking, Cloud, Containers, IaC, CI/CD, Kubernetes, and SRE.

## Exam Blueprint
- **Section 1: Systems & Networking (25%):** Linux kernel mechanics, systemd, memory/CPU analysis, TCP/IP, DNS, and TLS.
- **Section 2: Containers & Orchestration (25%):** Linux cgroups/namespaces, UnionFS, Docker Compose, Kubernetes control plane, Pod scheduling, and Ingress.
- **Section 3: Cloud & Infrastructure as Code (25%):** AWS VPC routing, IAM policy evaluation, Terraform state lifecycle, and drift management.
- **Section 4: Observability, Security & SRE (25%):** PromQL metrics, incident response lifecycles, DevSecOps scanning, backup validation, and RTO/RPO calculation.
