# Weekly Reporting System

Every Sunday, learners must submit a completed weekly report documenting their study hours, conceptual reflections, debugging logs, and self-assessment.

## Submission Instructions
1. Copy `weekly-reports/template.md` to `weekly-reports/week-XX-report.md` (e.g., `weekly-reports/week-03-report.md`).
2. Fill out every section thoroughly.
3. Commit the report to your weekly branch:
   ```bash
   git add weekly-reports/week-XX-report.md
   git commit -m "docs(reports): submit week-XX progress report"
   ```
4. Push to remote and link the report in your Pull Request and Weekly Report Issue.

Reports that merely list completed tasks without deep explanations or debugging logs will be rejected.
