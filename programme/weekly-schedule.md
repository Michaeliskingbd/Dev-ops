# Weekly Learning Schedule & Operating Cadence

A disciplined, predictable weekly routine is the foundation of high-performance technical learning.

---

## 📅 Daily Hourly Allocation

Targeting approximately **3 to 4 hours per weekday** and **2 to 3 hours on Saturday**:

```text
┌─────────────────┬──────────┬─────────────────────────────────────────────────┐
│ Time Block      │ Duration │ Activity Focus                                  │
├─────────────────┼──────────┼─────────────────────────────────────────────────┤
│ Block 1: Theory │ 60–90 m  │ • Deep read of weekly curriculum document       │
│ & Foundations   │          │ • Official documentation & RFC inspection       │
│                 │          │ • Taking structured notes & architectural flow  │
├─────────────────┼──────────┼─────────────────────────────────────────────────┤
│ Block 2: Hands- │ 90–120 m │ • Terminal implementation of daily exercises    │
│ On Engineering  │          │ • Completing scheduled weekly assignments       │
│                 │          │ • Testing configurations & breaking edge cases  │
├─────────────────┼──────────┼─────────────────────────────────────────────────┤
│ Block 3: Review │ 30 m     │ • Capturing terminal output & evidence logs     │

│                 │          │ • Updating daily engineering log                │
└─────────────────┴──────────┴─────────────────────────────────────────────────┘
```

## 🗓️ Day-by-Day Cadence

### Monday: Foundations & Environment Kickoff
- **Morning:** Review weekly objectives and prerequisite checklist.
- **Deep Study:** Core theoretical foundations and architectural concepts.
- **Implementation:** Complete Assignment 1 (Environment setup and basic mechanics).
- **Deliverable:** Working baseline environment and initial Git commit.

### Tuesday: Deepening Technical Implementation
- **Deep Study:** System internals, configuration parameters, and protocols.
- **Implementation:** Complete Assignment 2 (Core implementation).
- **Deliverable:** Working configuration or script committed to branch.

### Wednesday: Intermediate Challenges & Mid-Week Check
- **Deep Study:** Edge cases, performance considerations, and failure modes.
- **Implementation:** Complete Assignment 3 (Intermediate implementation).
- **Mid-Week Sync:** Review progress against weekly goals; raise blockers if any.
- **Deliverable:** Working implementation and preliminary testing logs.

### Thursday: Advanced Integration & Security
- **Deep Study:** Security hardening, least privilege, and production best practices.
- **Implementation:** Complete Assignment 4 (Advanced integration).
- **Deliverable:** Production-hardened configuration verified with security checks.

### Friday: Troubleshooting & Submissions Polish
- **Deep Study:** Common pitfalls, error analysis, and debugging techniques.
- **Implementation:** Complete Assignment 5 (Troubleshooting scenario).
- **Pre-flight Check:** Run `python scripts/validate_submission.py --week XX`.
- **Drafting:** Complete initial draft of weekly report in `weekly-reports/week-XX-report.md`.
- **Deliverable:** Open Pull Request for mentor review.

### Saturday: Challenge, Assessment & Live Mentor Session
- **Morning (90 mins):** Complete the Weekly Practical Engineering Challenge.
- **Live Session (60–90 mins):**
  - Verbal knowledge check with mentor (Conceptual Understanding).
  - Injected troubleshooting drill (Independent Problem Solving).
  - Code walkthrough and feedback review.
- **Finalization:** Mentor inputs score in [assessments/weekly/](assessments/weekly/).

### Sunday: Mandatory Rest & Reflection
- **Zero mandatory assignments.**
- Rest your brain to allow consolidation of technical memory.
- Optional light reading or technical podcast listening only.
