# Master Assessment Rubric & Competency Framework

## 1. Detailed 100-Point Category Breakdown

### 1. Conceptual Understanding (20 Points)
- **18–20 pts (Exemplary):** Explains mechanics, architecture, RFC protocols, and failure modes fluently using precise engineering terminology without hesitation.
- **15–17 pts (Competent):** Clear high-level understanding with minor hesitation on low-level kernel/network details.
- **12–14 pts (Developing):** Relies heavily on high-level generalities; cannot explain edge cases.
- **<12 pts (Unsatisfactory):** Fundamentally misunderstands core concepts or quotes memorized tutorial definitions without comprehension.

### 2. Practical Implementation (40 Points)
- **36–40 pts (Exemplary):** Flawless execution. Code/config is idiomatic, clean, modular, properly parameterized, secure, and production-ready.
- **30–35 pts (Competent):** Working implementation meeting all core requirements; minor formatting or non-critical configuration improvements needed.
- **24–29 pts (Developing):** Functional with caveats; fragile error handling or partial hardcoding.
- **<24 pts (Unsatisfactory):** Does not run, fails critical safety checks, or misses major assignment requirements.

### 3. Independent Problem Solving (20 Points)
- **18–20 pts (Exemplary):** Diagnoses injected failure systematically within 15 minutes; articulates hypotheses before executing diagnostic commands; verifies resolution cleanly.
- **15–17 pts (Competent):** Identifies and fixes failure within 30 minutes with minimal prompt; follows structured diagnostic steps.
- **12–14 pts (Developing):** Randomly modifies configurations hoping for a fix; takes over 30 minutes.
- **<12 pts (Unsatisfactory):** Unable to locate failure or requires mentor to provide the solution.

### 4. Technical Documentation (10 Points)
- **9–10 pts (Exemplary):** Comprehensive, clear, reproducible markdown documentation with architecture diagrams, sample logs, and clear runbooks.
- **7–8 pts (Competent):** Good documentation covering setup and results; minor omissions in edge-case notes.
- **<7 pts (Unsatisfactory):** Sparse, copy-pasted, or missing required sections.

### 5. Consistency & Completion (10 Points)
- **10 pts (Full):** Submitted on time, all 5 assignments complete, clean conventional Git commits, structured weekly report complete.
- **<8 pts (Partial):** Missing deliverables or submitted after deadline without prior notification.

## 2. Competency Tracking Matrix

| Competency Tier | Criteria for Advancement |
|---|---|
| `NOT_STARTED` | Curriculum has not yet commenced. |
| `LEARNING` | Reading documentation, executing initial walkthroughs. |
| `GUIDED` | Can complete assignments with mentor assistance or reference guides. |
| `INDEPENDENT` | Successfully builds, explains, and troubleshoots systems autonomously. |
| `NEEDS_REASSESSMENT` | Regression observed during milestone exams or multi-service integrations. |
